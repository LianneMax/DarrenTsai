# House illustration

`public/house-3d.webp` is an AI-generated illustration created with the built-in image generation tool for the approved local concept. It is illustrative, not a property listing or an appraisal.

Direction: a polished three-dimensional suburban house, transparent background, slate roof, pale cyan siding, white trim, restrained landscaping, soft studio lighting, using the site's existing slate/teal/cyan palette. Product labels are accessible HTML layered over the image, not generated text.

Only the optimized 840 × 840 WebP is shipped. The ZIP reference has separate attribution in `public/zip-data/README.txt`.
